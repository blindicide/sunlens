# Архитектура и границы безопасности

GUI работает от обычного пользователя. Он не запускает shell-команды из профилей,
не повышает собственные привилегии и не считает запуск процесса доказательством VPN.
TUN недоступен до реализации узкого авторизованного помощника и проверки
идемпотентного восстановления маршрутов/DNS.

Модель узла не зависит от ядра. Адаптеры обязаны отклонять неподдержанные поля.
sing-box и Xray требуют разных схем и отдельных проверок capabilities/version.
Конфигурация проверяется до сетевых изменений. Секреты не передаются в argv,
не выводятся в diagnostics и не попадают в контролируемые Git fixtures.

SQLite хранит профили и будущую историю. Подписка обновляется целиком внутри
транзакции: ошибка загрузки/парсинга не удаляет текущие узлы. ID узла не зависит
от позиции, имени в интерфейсе или backend tag.

Сетевой помощник пока отсутствует. Будущий протокол должен принимать только
типизированные операции с проверенными параметрами, а не команды или произвольные
пути к исполняемым файлам. Требуются peer authorization, защита upstream,
журнал восстановления и независимая очистка при аварии/перезагрузке/удалении.
