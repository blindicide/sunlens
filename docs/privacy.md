# Данные и приватность

В `QStandardPaths::AppDataLocation` сохраняется `profiles.sqlite`: URL подписок
(включая токены), credentials серверов, метки, время/статус обновления и выбор
сервера. Это **не зашифрованное хранилище**. Интеграции с DPAPI/keyring пока нет.
На Unix приложение создаёт каталог 0700 и файл 0600, использует umask 0077
и отказывается запускать GUI от root. На Windows применяется каталог данных
пользователя; защита ACL и DPAPI требует отдельной проверки.

Диагностический список GUI не содержит credentials или URL. Ошибки импорта
не цитируют исходные строки, а сетевые ошибки — секретный URL. Не прикладывайте
базу данных и исходные ссылки к публичным issue. Ввод секретов очищается после
успешного импорта; гарантированное стирание всех копий строк в памяти не обещается.
Разделы имён и меток отображаются как введены пользователем/провайдером.

Телеметрия и история посещённых адресов не ведутся. Linux helper читает реальные
L3-счётчики TUN при активном туннеле; GUI-персистентная аналитика пока отсутствует.
Запрос подписки раскрывает её провайдеру факт обращения. Ввод HTTPS URL
является разрешением загрузить его; автоматических фоновых запросов при старте нет.

Резервная копия SQLite содержит секреты. Для удаления локальных данных закройте
приложение и удалите его каталог данных. Безопасное стирание с SSD не гарантируется.
