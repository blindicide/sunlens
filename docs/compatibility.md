# Совместимость

## Текущий статус

Доступны проверка HTTP CONNECT и SOCKS5, а также экспорт конфигурации для ручного
запуска sing-box в Windows. Автоподключение и живая проверка TUN пока отсутствуют.
Нельзя трактовать успешный тест HTTPS или GUI smoke-test как совместимость с VPN.

## Планируемые форматы

Plain/base64 списки URI VLESS, VMess, Trojan и Shadowsocks, затем только
подтверждённые fixtures варианты. YAML/Clash, JSON-массивы, SIP008 и произвольные
vendor-форматы не принимаются молча. Неподдержанный параметр должен вызвать
ошибку до обновления рабочих профилей.

Официальные источники для независимой реализации:
- https://sing-box.sagernet.org/configuration/inbound/tun/
- https://github.com/XTLS/Xray-core/blob/main/proxy/tun/README.md

Документация upstream может описывать функции новее закреплённой версии.
Каждая версия/функция требует проверки конкретным исполняемым файлом.
