# Совместимость

## Текущий статус

TUN и подключение ни с одним ядром пока не реализованы. Нельзя трактовать наличие
кнопки или успешный GUI smoke-test как совместимость с VPN.

## Реализованные форматы импорта

- UTF-8, plain/base64 (обычный и URL-safe) список URI, один узел на строку.
  Пустые строки допускаются; комментарии не интерпретируются.
- VLESS: UUID, `encryption=none`, TCP/WS, security none/TLS, SNI,
  WS host/path, flow xtls-rprx-vision только с TCP/TLS.
- VMess: base64 JSON v2, UUID, alterId=0; TCP/WS, TLS/SNI,
  security auto/aes-128-gcm/chacha20-poly1305/none. Маскировка TCP не поддерживается.
- Trojan: пароль, TCP/WS, обязательный TLS, SNI, WS host/path.
- Shadowsocks SIP002 base64 userinfo и legacy base64 полного адреса;
  aes-128-gcm/aes-256-gcm/chacha20-ietf-poly1305, без плагинов.
- Ручная форма: TCP, те же протоколы, credentials, TLS/SNI и метод.

Это совместимость **импорта**, а не подтверждённое подключение ядром.
REALITY, gRPC, Hysteria, SS2022, plugins, insecure TLS, YAML/Clash,
JSON-массивы и SIP008 пока отклоняются. Неизвестные/повторные параметры
и одна повреждённая строка отклоняют весь документ, не частичный список.
Лимиты: 4 МиБ, 10000 узлов. Одинаковые узлы внутри группы дедуплицируются.

Подписки загружаются только по HTTPS, без userinfo/фрагмента и cookies.
Перенаправления не выполняются: укажите конечный URL. Deadline 15 с;
до двух повторов при HTTP 429/5xx и временных сетевых ошибках.
Проверка TLS не отключается. Тесты используют явно разрешённый loopback HTTP,
который недоступен через настройки приложения.

ID сохраняется при перестановке и изменении метки провайдером. Пользовательская
метка хранится отдельно. Изменение endpoint/credentials означает новый узел;
повторное появление прежнего узла даёт прежний ID, но удалённая метка не сохраняется.
Объявленные quota/expiry пока не обрабатываются.

Официальные источники для независимой реализации:
- https://sing-box.sagernet.org/configuration/inbound/tun/
- https://github.com/XTLS/Xray-core/blob/main/proxy/tun/README.md

Документация upstream может описывать функции новее закреплённой версии.
Каждая версия/функция требует проверки конкретным исполняемым файлом.
