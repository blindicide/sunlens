# План к v1.0.0

Вместо отсутствующих удалённых issues используется этот контрольный список.
Задачи закрываются только проверяемыми результатами.

## M1 — основа
- [x] C++20, CMake, Qt Quick, VERSION, CTest, SVG-исходники.
- [ ] CI Windows x64 и Linux x86_64 подтверждён удалённым запуском.
- [ ] Лицензия одобрена владельцем; создан публичный репозиторий.

## M2 — профили
- [x] Нормализованные узлы VLESS, VMess, Trojan, Shadowsocks (ограничения в compatibility).
- [x] Строгий plain/base64 URI list; неизвестные поля отклоняются.
- [x] Транзакционный SQLite и стабильные ID при обновлении.
- [x] HTTPS-подписки: лимит размера, timeout, ошибки, сохранение рабочего набора.
- [x] GUI импорта и выбора, тесты повреждённых данных.
- [ ] Проверка живого HTTPS-провайдера и GUI взаимодействий на Windows.

## M3 — Linux/sing-box
- [x] Версия/хеш sing-box 1.14.4, генерация и реальная неповышенная проверка конфигурации.
- [ ] Узко ограниченный привилегированный помощник с авторизацией.
- [ ] Транзакция маршрутов/DNS, восстановление и журнал crash recovery.
- [ ] Cleanup временных секретов после SIGKILL GUI; выбор непересекающегося TUN subnet.
- [ ] Реальный connect/disconnect/reconnect и внешняя проверка DNS/трафика.

## M4–M6 — матрица и безопасность
- [ ] Windows/sing-box TUN.
- [ ] Linux/Xray и Windows/Xray TUN с независимыми конфигурациями.
- [ ] Смена узла/ядра, неверные credentials, timeout, аварийный выход.
- [ ] IPv4/IPv6, TCP/UDP, LAN bypass, DNS, защита upstream от петли.
- [ ] Сон/пробуждение, смена интерфейса, отмена elevation, crash/reboot cleanup.

## M7 — аналитика и UI
- [ ] Реальные счётчики без двойного учёта при сбросах; unavailable при отсутствии.
- [ ] История задержки, события, retention и настройка приватности.
- [ ] Dashboard, подписки, доступность, светлая/тёмная тема.

## M8–M9 — выпуск
- [ ] Лицензии Qt/ядер/драйвера, проверенные зависимости и SBOM.
- [ ] DEB, RPM и NSIS EXE: установка/GUI/удаление на чистых ОС.
- [ ] Полная живая матрица TUN (2 ОС × 2 ядра), внешняя проверка утечек.
- [ ] Проверенные логи, hashes, metadata, точный tag/version, changelog.
- [ ] Одобрение публикации; публичные ссылки на все три артефакта.
