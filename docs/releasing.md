# Выпуск

**v0.1.1 — предварительная версия, не готовый VPN.** Workflow `Preview packages`
для этой версии проверяет установку, запуск и удаление двух пакетов: Ubuntu
24.04 amd64 (`.deb`) и Windows x64 (один NSIS `.exe`, установка требует интернет).
На Windows `sing-box check` проверяет два профиля без запуска TUN. Сборка ветки
ничего не публикует. Тег `v0.1.1` публикует предварительный выпуск только после
успеха обеих платформ и проверки двух загруженных файлов в черновике.

**Стабильный выпуск заблокирован.** Не создавать тег v1.0.0 до выполнения
`docs/milestones.md`. Другие теги не проходят проверку этого workflow.

Единый источник версии — `VERSION`; CMake и executable используют его напрямую.
Запрещены принудительный перенос опубликованных тегов и замена бинарников версии.
Исправления опубликованной версии требуют PATCH.

До стабильного выпуска обязательны:
1. Полная проверка обязательств по Qt, ядрам и Wintun и дополнительных артефактов.
2. Hash-pinned зависимости, полная живая матрица TUN на двух ОС.
3. Настоящие DEB/RPM/NSIS с cores/helpers/runtime и проверкой чистой установки.
4. Проверенные install/start/connect/disconnect/uninstall, crash recovery.
5. SHA-256, SBOM, notices и manifest (commit, baseline, Qt, cores).
6. Точный SemVer tag/version, успешные gates, разрешение владельца.

Рецепты ручной проверки пакетов: [packaging/README.md](../packaging/README.md).
