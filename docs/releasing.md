# Выпуск

**Выпуск заблокирован.** 0.1.1 — идентификатор разработки, не готовый VPN.
Не создавать тег v1.0.0 до выполнения `docs/milestones.md`.

Единый источник версии — `VERSION`; CMake и executable используют его напрямую.
Запрещены принудительный перенос опубликованных тегов и замена бинарников версии.
Исправления опубликованной версии требуют PATCH.

До включения публикации обязательны:
1. Решение владельца о лицензии и проверка obligations Qt, ядер, Wintun.
2. Hash-pinned зависимости, полная живая матрица TUN на двух ОС.
3. Настоящие DEB/RPM/NSIS с cores/helpers/runtime и проверкой чистой установки.
4. Проверенные install/start/connect/disconnect/uninstall, crash recovery.
5. SHA-256, SBOM, notices и manifest (commit, baseline, Qt, cores).
6. Точный SemVer tag/version, успешные gates, разрешение владельца.

Текущий release workflow намеренно завершается ошибкой до сборки/публикации:
он не создаёт пустые пакеты, не выдаёт portable executable за installer и
не заменяет ручное подтверждение фальшивой успешной проверкой.
