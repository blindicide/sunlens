# История изменений

## [0.1.1] — предварительная версия

### Added
- Проверка HTTP CONNECT и SOCKS5 запросом HTTPS через выбранный прокси.
- Экспорт конфигурации Windows TUN без учётных данных для ручной проверки.
- Подготовка каталога Windows x64 с Qt, sing-box 1.14.5 и Wintun 0.14.1.
- Пакет Ubuntu 24.04 / Linux Mint 22 amd64 и установщик Windows x64. Для установки Windows нужен интернет: setup получает sing-box и Wintun у их издателей и проверяет SHA-256.

### Ограничения
- Проверка HTTPS не меняет системную сеть. Запуск TUN остаётся ручным и не проверен в реальных условиях. Kill switch отсутствует.
