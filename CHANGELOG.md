# История изменений

## [Unreleased] — разработка 0.1.0

### Added
- Кнопка проверки профиля через HTTPS в sing-box и Xray без TUN и прямого
  обхода профиля.
- Обычный запуск установленного клиента из меню приложений, выбор ядра рядом
  с подключением, автоматический выбор первого профиля и закрытая CI-сборка
  проверочных установщиков.
- GitHub Actions для сборки и проверки DEB/RPM; подготовка черновика GitHub
  Release с контрольными суммами заблокирована до допуска к выпуску.
- Основа C++20/Qt Quick, единая версия и тест загрузки интерфейса.
- Контрольный список критериев v1.0.0 с явными блокерами.
- Строгий импорт четырёх протоколов, plain/base64 URI lists и ручная TCP-форма.
- Транзакционные HTTPS-подписки с timeout, retry и лимитом размера.
- SQLite, стабильные ID групп/узлов, пользовательские метки и выбор сервера.
- Тесты парсинга, rollback после частичной SQL-записи и loopback HTTP-сбоев.
- Manifest sing-box 1.14.4 с SHA-256, ограниченная загрузка development-зависимости.
- Генерация Linux TUN-конфигурации четырёх протоколов и режимов proxy/direct/rules.
- Асинхронная проверка настоящим sing-box из GUI, без запуска VPN.
- Реальные неповышенные проверки 15 конфигураций и clang static analyzer в Linux CI.
- Ограниченный Linux helper, polkit policy, закрытый pipe IPC и durable recovery journal.
- TunnelManager с timeout, откатом и восстановлением после аварий ядра/помощника.
- Изолированные live VLESS TUN-тесты TCP/UDP/IPv4/IPv6/DNS с внешним packet capture.
- GUI Connect/Disconnect/Recover через установленный helper с отдельным подтверждением polkit.
- Различение готовности TUN и неподтверждённой доступности сервера, живые L3-счётчики.
- Настройки DNS и подтверждение отключения перед выходом из GUI.
- Независимый адаптер Xray 26.11.9, выбор ядра в GUI и закреплённая загрузка ZIP.
- Изолированный live TUN для Xray/Linux: IPv4/IPv6 TCP/UDP, DNS, внешний захват
  и восстановление после отключения или аварии.
- Локальная SQLite-аналитика TUN L3, дельты, скорость, агрегаты по серверам и
  подпискам, история событий и ручная TCP-проба с настраиваемым сроком хранения.
- Локальный DEB для Ubuntu 24.04 с проверкой метаданных, обоих ядер, helper,
  policy polkit и recovery unit; отдельный сценарий проверки в чистой VM.

### Changed
- Главный экран с отдельной карточкой подключения и приглушённым фоном
  SUN / LENS; сетевые параметры находятся во вкладке «Настройки».
- Трафик и скорость отображаются в Б, КБ, МБ или ГБ по масштабу значения.
### Fixed
- DNS startup sing-box: удалён недопустимый detour к пустому direct outbound,
  который принимался check-командой, но блокировал настоящий запуск.
### Security
- `prerm` блокирует удаление при живом helper или незавершённом откате;
  новые подключения запрещены, пока выполняется пакетное обслуживание.
- Credentials отправляются помощнику только после авторизованного handshake;
  текстовый внутренний агент pkexec отключён, developer-путь для elevation запрещён.
- HTTPS без отключения TLS и без автоматических redirects/cookies.
- Закрытые Unix-права данных, запрет root GUI и отсутствие секретов в view model.
- Отказ от неподтверждённого ядра, закрытые временные config-файлы и ограниченный вывод QProcess.
